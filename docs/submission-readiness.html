Copy-ready project description

RescueRelay helps food-rescue coordinators recover scheduled pickups after a volunteer cancels. It checks structured capacity, training, availability and receiving constraints, retrieves policy evidence, and proposes feasible replacements or an escalation. Coordinators explicitly approve assignments; volunteer acceptance, pickup, delivery and recipient acknowledgment remain separate. The prototype includes web and mobile clients, durable organization-scoped records and optional AI investigation, retrieval, document, memory and tracing adapters. The current demonstration uses synthetic records and sealed shelf-stable goods, with documented local and bounded live-provider test results.
