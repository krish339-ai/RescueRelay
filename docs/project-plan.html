How the plan connects to the project

Build guide explains the implementation sequence and local workflow. Optional AI contract defines the additional integration boundary. Architecture plan groups the same work into technical workstreams. Verification record preserves observed results and untested targets. Official documentation covers the product and technical reference.

This is a local-first reference build with synthetic demonstration data and in-app notifications. Stage completion does not imply production readiness, live dispatch, food-safety certification, signed native applications, or app-store availability.
