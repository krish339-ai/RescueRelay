# Native-client visual references

These JPEGs were captured from the actual Expo React Native Web export on 2026-10-30 through the supported managed browser preview. The application is displayed in a 430px-wide canvas inside a desktop browser; the backing API was the real Fastify implementation with isolated, synthetic in-memory data.

- `01-native-web-welcome.jpg`: welcome and demo role selection.
- `02-native-web-dashboard.jpg`: coordinator dashboard after a tested volunteer cancellation returned an assignment to recovery.
- `03-native-web-recovery-evidence.jpg`: real proposed volunteer, synthetic travel disclaimer, and cited operational policy evidence.
- `04-native-web-ai-status.jpg`: optional AI Assist, global external calls OFF, disabled/unconfigured/live-unverified capability disclosure.
- `05-native-web-ai-consent.jpg`: local consent preparation showing the selected Nebius + Pinecone + LangSmith data-transfer preview. No external service ran.
- `06-native-web-ai-execution-blocked.jpg`: payload hash, bounded request budget, retention/cost warning, and disabled execution until operator configuration and fresh explicit consent.
- `07-native-web-ai-receipts.jpg`: explicit local receipt refresh with an honest empty-state/uncertain-outcome warning; web-only upload workflows are clearly distinguished.

**These are not Android/iOS device or simulator screenshots.** Native packaging was verified by Metro/Hermes exports; native compilation, installation, hardware SecureStore behavior, and signing still require the documented platform checks. No live food dispatch or external notifications occurred.
